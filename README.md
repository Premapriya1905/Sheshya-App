**Sheshya App**

This Flutter app is a colorful, interactive learning platform designed specifically for kindergarten through 2nd grade children.
It features engaging question types including fill-in-the-blanks, image matching, audio questions, and sentence formation exercises,
all wrapped in a kid-friendly interface with animations and immediate feedback.

It uses Flutter's widget system for the UI, incorporates audio packages from google for sound in mp3 format and confetti for celebrations.
The design prioritizes large, touchable elements with bright colors and immediate feedback, making it perfect for young learners.
